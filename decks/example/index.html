    Layout

    Eyebrow labels and constrained content areas

    <slide-eyebrow> renders the small label above the heading. It's a good way to orient the audience within a longer deck.

    .slide-content is a CSS class that constrains the content to a readable 48 rem max-width. Add --wide for 64 rem, or --stack to turn it into a flex column with a gap.

    Pair an eyebrow with an h2 and a slide-content wrapper and you have a consistent, scannable slide structure.

    shared/style.css — .slide-content, .slide-eyebrow

    Data cards

    Metric grid — auto-fit stat display

    Use <metric-grid> with <metric-card> children to show 2 or 3 stats side by side. Columns auto-fit — no extra config needed.

    Data cards

    Feature cards — icon, title, body

    Each component is a plain HTMLElement subclass. No React, no Vue, no build-time compilation. Works in any browser that supports custom elements. Every element inside a slide can use Tailwind classes directly. The full utility set is available — no safelisting, no JIT caveats. Drop an index.html and deck.js into decks/my-talk/ and it's live. Vite handles the build entry point automatically.

    topic-header — pinned badge row

    Use <topic-header> to pin a numbered badge to the top-left corner of every slide in a series. Navigate down to see it hold its position as content changes.

    The section fills the full slide height so Reveal anchors it at top: 0. The badge is position: absolute at a fixed offset — it never shifts regardless of how tall the content is.

    The badge stays put as you navigate

    Add muted to dim the badge — useful for slides that reference a previously covered topic.

    <topic-header code="01" label="First Topic"></topic-header> <topic-header code="02" label="Previously Covered" muted></topic-header>
    Extending Lectern

    Adding a component in three steps

    export class MySlide extends HTMLElement { connectedCallback() { const title = this.getAttribute('title') ?? '' const section = document.createElement('section') section.innerHTML = `<h2>${title}</h2>` this.replaceWith(section) } } customElements.define('my-slide', MySlide)
    import './my-slide.js' <my-slide title="Hello"></my-slide>

    type="module" scripts run after the document is fully parsed. Custom elements upgrade immediately, so querySelectorAll in connectedCallback always sees the full DOM.
    Theming

    CSS variable theming

    All component colours are driven by --deck-* CSS variables defined in shared/style.css. Override any token in a scoped theme file to change the entire look.

    :root { --deck-bg: #080b12; --deck-surface: #111827; --deck-accent: #f87171; --deck-code: #7dd3fc; } .reveal.deck-my-theme { --deck-bg: #0f1729; --deck-surface: #1e2d4a; --deck-accent: #60a5fa; --deck-code: #a78bfa; }

    Create shared/themes/my-theme.css, override the variables, import it in deck.js, and add the class to the reveal root div.
